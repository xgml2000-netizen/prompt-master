# Contributing

Thanks for helping improve Prompt Master.

## Good Contributions

- New reusable prompt templates
- Before/after prompt improvement examples
- Chinese-English prompt translation examples
- Checklist improvements with concrete examples
- Fixes to the Codex skill instructions

## Template Contribution Format

When adding a template, include:

- A short title
- The use case
- A copy-ready prompt
- Optional Chinese version
- Notes about when to use it

## Quality Bar

A good prompt should:

- State the role and task clearly
- Include enough context placeholders
- Define output format
- Include constraints and negative instructions
- Be reusable by someone who did not write it

## Pull Request Checklist

- [ ] The contribution solves a real workflow
- [ ] Placeholders are clear and easy to replace
- [ ] Markdown renders correctly
- [ ] Chinese and English content preserve the same intent when both are included
- [ ] Links in README or docs are updated when needed
