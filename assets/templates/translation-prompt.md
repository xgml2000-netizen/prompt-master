# Chinese-English Prompt Translation Template

```markdown
Translate the following prompt from [source language] to [target language].

Translation rules:
- Preserve the original structure, headings, bullets, code blocks, and placeholders.
- Do not translate code identifiers, file paths, API names, command-line flags, environment variables, or quoted literals.
- Preserve constraints, guardrails, and output format exactly.
- Translate naturally for AI instruction-following, not word-for-word.
- If a phrase is ambiguous, add a short translator note after the translation.

Output format:
## Translation
[translated prompt]

## Notes
- [Only include notes when needed]

Original prompt:
[paste prompt]
```

## 中文版

```markdown
请把下面的提示词从[源语言]翻译成[目标语言]。

翻译规则：
- 保留原始结构、标题、列表、代码块和占位符。
- 不要翻译代码标识符、文件路径、API 名称、命令行参数、环境变量或引号中的字面量。
- 完整保留约束、护栏和输出格式。
- 按 AI 指令的自然表达翻译，不要逐字硬译。
- 如果某个表达有歧义，请在译文后添加简短译注。

输出格式：
## 译文
[翻译后的提示词]

## 备注
- [仅在必要时填写]

原始提示词：
[粘贴提示词]
```
