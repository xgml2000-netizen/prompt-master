# Prompt Quality Checklist

Use this checklist before publishing or reusing a prompt.

## 1. Goal

- Is the task specific?
- Does the prompt say what success looks like?
- Does it avoid broad requests like "make it better" without criteria?

## 2. Role

- Does the model know what perspective to take?
- Is the role useful for the task rather than decorative?

## 3. Context

- Are inputs, background, audience, and constraints included?
- Are assumptions explicit?
- Are time-sensitive claims dated?

## 4. Boundaries

- Does the prompt say what not to do?
- Does it define scope and exclusions?
- Does it explain when to ask clarifying questions?

## 5. Output

- Is the expected format clear?
- Are headings, tables, JSON fields, or bullet rules specified when needed?
- Can the output be evaluated quickly?

## 6. Examples

- Are examples included when they reduce ambiguity?
- Do examples match the real use case?
- Are edge cases covered?

## 7. Safety and Reliability

- Are risky areas named?
- Does the prompt require sources for factual claims when needed?
- Does it distinguish facts, assumptions, and opinions?

## 8. Reusability

- Are placeholders easy to replace?
- Is the prompt free of one-off private context?
- Can another user understand it without extra explanation?

## Simple Score

| Score | Meaning |
| ---: | --- |
| 0-2 | Vague or unreliable |
| 3 | Usable but needs cleanup |
| 4 | Strong and reusable |
| 5 | Production-ready |
