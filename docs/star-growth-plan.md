# Star Growth Plan

This repo should win Stars by being immediately useful, easy to scan, and easy to share.

## Positioning

Prompt Master is not just another prompt list. Its strongest angle is:

> A bilingual prompt engineering skill and template library for Codex and AI agents.

That positioning is specific enough to remember and broad enough to grow.

## Content Roadmap

### Phase 1: Make the repo useful at first glance

- Add 10-20 copy-ready templates.
- Add before/after examples for each template category.
- Add a prompt quality checklist.
- Add Chinese-English examples to make the bilingual advantage obvious.

### Phase 2: Make it searchable

Add GitHub topics:

- `prompt-engineering`
- `prompts`
- `prompt-template`
- `ai-agent`
- `codex`
- `chatgpt`
- `llm`
- `chinese`
- `bilingual`
- `developer-tools`

Use keywords naturally in README headings and template names.

### Phase 3: Make it shareable

Good share posts should show a concrete improvement, not a vague announcement.

Example post:

```text
I built Prompt Master, a bilingual Codex skill for improving AI prompts.

It includes:
- copy-ready templates
- prompt review checklist
- Chinese-English translation rules
- before/after prompt examples

Repo: https://github.com/xgml2000-netizen/prompt-master
```

Chinese version:

```text
我做了一个 Prompt Master：面向 Codex / AI Agent 的双语提示词优化技能库。

目前包含：
- 可直接复制的提示词模板

- 中英文提示词翻译规则
```

## Star Conversion Tips

- Put the best template links above the fold in README.
- Use a strong one-line value proposition.
- Add screenshots or short GIFs once the skill has a visible workflow.
- Keep commits frequent and meaningful.
- Add issues labeled `good first issue` for community contributions.
- Pin the repo on your GitHub profile.

## Metrics to Watch

- README views
- Stars per share post
- Issues or template requests
- Forks
- External links and mentions
